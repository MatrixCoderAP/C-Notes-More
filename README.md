# Math, Physics, and Questionable Amounts of C++

I'm a Grade 9 student learning C++ and C# while slowly working my way toward calculus, physics, electrical engineering, and eventually quantum hardware.

This repository is basically a record of me throwing new concepts into small projects until they make sense.

## Projects

### 01 — Circumference Calculator

A simple calculator for finding the circumference of a circle. One of my first steps into mixing formulas with C++.

### 02 — Endgame Character Format

An early formatting experiment involving character information and console output.

### 03 — Mini Choice Game

A small text-based game where the player makes choices.

### 04 — Mini Choice Game V2

An upgraded version of the original choice game with more practice using conditions and program flow.

### 05 — Projectile Analysis

A physics-based calculator for analyzing projectile motion.

### 06 — Quadratic Formula Calculator

Solves quadratic equations using the quadratic formula.

### 07 — Vector Component Calculator

Breaks a vector into its horizontal and vertical components using trigonometry.

### 08 — Quadratic Formula Calculator V2

An improved version of my original quadratic calculator (Can handle complex and imaginary discriminants)

### 09 — Classical Mechanics Calculator

A collection of classical mechanics formulas, including force, weight, momentum, energy, work, and projectile motion.

### 10 — Receipt Analyzer

Uses a C++ vector to:

* Calculate a receipt subtotal
* Apply a chosen tax rate
* Find the average item price
* Identify prices above or below the average

### Ball Drop Physics
