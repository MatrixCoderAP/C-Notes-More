# C++ Learning Projects

This repository contains small C++ projects I built while learning programming, mathematics, and physics.

My goal is to strengthen my problem-solving skills by turning math and physics concepts into working code. These projects show my progress from basic input/output programs toward math-based and physics-based tools.

---

## Projects

### Circumference Calculator
Calculates the circumference of a circle using user input.

### RPG Character Creator
A simple character creation program using variables, user input, and formatted output.

### Mini Choice Game
A basic text-based choice game using conditional statements.

### Mini Choice Game v2
An improved version of the choice game with more logic and structure.

### Projectile Analyzer
Uses quadratic equations to analyze projectile motion, including height over time.

### Quadratic Formula Calculator
Solves quadratic equations using the quadratic formula.

### Quadratic Formula Calculator v2
An improved version of the quadratic formula calculator.

This version classifies the roots using the discriminant and handles:

- Two real roots
- One repeated real root
- Two complex roots
- Non-quadratic input when `a = 0`

This project helped me connect algebra, imaginary numbers, and programming logic.

### Vector Component Calculator
Calculates the x- and y-components of a vector using magnitude, angle, trigonometry, and degree-to-radian conversion.
